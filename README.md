# AuraWeave: Generative Ambient Soundscape & Visualizer Studio

## Overview
AuraWeave is an immersive, fully client-side ambient soundscape generator and visualizer built with the Web Audio API and HTML5 Canvas. It allows remote workers, students, and meditation practitioners to create customized, organic soundscapes layered with synchronized generative particle art to enhance deep focus, relaxation, or sleep.

## Key Features
- **Web Audio API Procedural Sound Generators:** 
  - *Cosmic Drone:* Warm harmonic synthesizer chords with adjustable low-pass filters.
  - *Velvet Rain:* Filtered pink noise texture simulating gentle rainfall.
  - *Solar Wind:* Modulating atmospheric air stream powered by dual oscillators and LFO sweep.
  - *Crystal Chimes:* Procedural meditative bell arpeggiator on a pentatonic scale.
- **Immersive Flow Visualizer:** Real-time HTML5 Canvas particle flow field that responds organically to active audio generators.
- **Quick Mood Presets:** Instantly switch between Deep Focus, Cosmic Sleep, Forest Rain, and Cozy Café sound profiles.
- **Focus Timer:** Built-in countdown timer for Pomodoro-style productivity sessions.
- **100% Static & Offline:** No external libraries, tracking, or network requests required.

## Local Run Instructions
1. Download or clone the project files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Click "Start Journey" to activate the audio context and visualizer.

*Note: Due to browser autoplay policies, clicking "Start Journey" is required before audio nodes can begin playback.*
